# CitaIA v1 — núcleo funcional

Incluye landing, registro/login con Supabase y dashboard que consulta clientes reales.

## Variables de Vercel
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Usa la URL y publishable key de `cliniaia`. Nunca pongas `service_role` en el navegador.

## Deploy
Sube el contenido al repositorio `hhector05/citaia` y despliega en Vercel.
